# SQL iteracja 1

Celem na pierwszą iteracje jest ogarnięcie podstaw:
nauka pracy z narzędziami do obsługi SQL, czytanie danych z tabel, filtrowanie, sortowanie, agregowanie

## Jak wygląda jedna lekcja

Każda lekcja trwa 45 minut i zaczyna się od krótkiego sprawdzenia wiedzy z poprzednich lekcji, tzn. krótka wejściówka oraz 
sprawdzenia pracy domowej.

Przykłady poleceń:

- Napisz query, które pokaże pierwsze 10 rekordów z tabeli `customers`.
- Napisz query, które wybierze tylko kolumny `customer_id`, `customer_name`
  i `country`.
- Napisz query, które znajdzie klientów z kraju `PL`.
- Napisz query, które pokaże zamówienia o wartości większej niż 100.
- Napisz query, które posortuje zamówienia od największej wartości.
- Napisz query, które policzy liczbę zamówień w tabeli `orders`.

Następnie przechodzimy do nowego tematu (najpierw teoria, potem zadania)

Na sam koniec krótkie podsumowanie i nowa praca domowa.
