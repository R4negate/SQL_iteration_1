# Zadania SQL - iteracja 1

Ten folder zawiera zadania praktyczne do pierwszej iteracji SQL.

Domyslnie baza danych PostgreSQL jest pusta, dlatego przed cwiczeniami z `SELECT` trzeba przygotowac dane:

1. Otworz folder `DDL`.
2. Uruchom skrypty SQL w kolejnosci od `00` do `03`.
3. Dopiero potem przejdz do zadan z odczytywania danych.

Po przygotowaniu bazy wykonuj zadania w kolejnosci:

1. `01_podstawowe_pojecia.md`
2. `02_select_from_limit.md`
3. `03_wybor_kolumn_aliasy.md`
4. `04_where_i_operatory.md`
5. `05_sortowanie_null_i_wzorce.md`
6. `06_agregacje_group_by.md`
7. `07_joiny_podstawy.md`

W zadaniach uzywaj tabel:

- `course.customers`
- `course.products`
- `course.orders`
- `course.order_items`
